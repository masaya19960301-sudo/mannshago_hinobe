# 配送センター日延集計アプリ

配送センター向けの「日延（ひのべ）案件」を記録・集計するための Google Apps Script（GAS）製ウェブアプリです。スマートフォン利用を主眼に、オレンジ系のシンプルなUIで構築しています。

## 機能

- **入力フォーム**: 配送日 / 伝票No・販売金額（最大10行の動的入力）/ 店舗名 / 販売担当者 / お客様名 / 理由 を登録
- **集計ダッシュボード**: 総件数・総日延金額・当月件数のサマリーカード、月別件数の棒グラフ、理由別の円グラフ、全レコード一覧
- **設定画面**: 「理由」マスタを追加・削除

## ファイル構成

```
Code.gs           # サーバーサイドロジック
appsscript.json   # GAS マニフェスト
index.html        # メインページ（ナビゲーション・ルーティング）
form.html         # 入力フォーム画面
dashboard.html    # 集計・ダッシュボード画面
settings.html     # 設定画面（理由マスタ管理）
style.html        # 共通CSS（インクルード用）
```

## スプレッドシート構成

初回 `doGet` 実行時に以下のシートとヘッダーが自動生成されます。

### `records` シート
| 列 | 内容 |
|---|---|
| A | タイムスタンプ |
| B | 配送日（YYYY-MM-DD） |
| C | 伝票No（`/` 区切りで結合） |
| D | 販売金額合計（数値） |
| E | 店舗名（数値） |
| F | 販売担当者 |
| G | お客様名 |
| H | 理由 |

### `reasons` シート
- 1列目に「理由」を1行1件で格納（初期値5件付き）

### `settings` シート
- 拡張用の「キー / 値」シート（現状未使用）

## デプロイ手順

### 1. スプレッドシートを準備
1. Google ドライブで新規スプレッドシートを作成
2. URL `https://docs.google.com/spreadsheets/d/【ここがID】/edit` の **ID** をメモ

### 2. Apps Script プロジェクトを作成
1. [Apps Script](https://script.google.com/) で「新しいプロジェクト」を作成
2. 本リポジトリの以下ファイルを、同名で全てプロジェクトに貼り付け
   - `Code.gs`
   - `appsscript.json`（プロジェクト設定で「『appsscript.json』マニフェストファイルをエディタで表示する」を有効化）
   - `index.html`, `form.html`, `dashboard.html`, `settings.html`, `style.html`
3. clasp を使う場合は `clasp push` で一括反映可能

### 3. スクリプトプロパティを設定
1. プロジェクト設定（歯車アイコン） → 「スクリプト プロパティ」
2. 「スクリプト プロパティを追加」をクリック
3. 次のキー・値を追加
   - **プロパティ名**: `SPREADSHEET_ID`
   - **値**: 手順1でメモしたスプレッドシートID

### 4. ウェブアプリとしてデプロイ
1. 「デプロイ」 → 「新しいデプロイ」
2. 種類: **ウェブアプリ**
3. 設定:
   - **次のユーザーとして実行**: 自分（=デプロイユーザー）
   - **アクセス権**: 用途に応じて選択
     - 社内のみ利用 → `所属組織内の全員（ドメイン名）`
     - 不特定ユーザー利用 → `全員`
4. 「デプロイ」を押下し、初回は OAuth 認可を実行
5. 発行されたウェブアプリURLをスマホでブックマーク

### 5. 初回動作確認
1. URLにアクセスすると `doGet` が走り、`records` / `reasons` / `settings` シートとヘッダーが自動生成されることを確認
2. 「入力」タブで1件登録 → スプレッドシートに行が追加されることを確認
3. 「集計」タブでサマリーとグラフ、一覧が表示されることを確認
4. 「設定」タブで理由を追加・削除し、入力フォームの選択肢に反映されることを確認

## バリデーション仕様

### クライアント側（送信前）
- 配送日: 必須
- 伝票No: 6桁の数字（`^\d{6}$`）
- 販売金額: 0以上の数値
- 店舗名: 必須・数字のみ
- 販売担当者・お客様名: 必須、空白文字（半角/全角スペース/タブ）禁止
- 理由: 必須（選択）

### サーバー側（`Code.gs` の `validateRecord_`）
- 同等のバリデーションを実施し、不正データはスプレッドシートに保存しません

## 補足

- ライブラリの追加インストール不要。Chart.js は `index.html` で CDN から読み込みます
- 通信はすべて `google.script.run` 経由
- HTML は `HtmlService.createTemplateFromFile` と `include()` で分割管理
- スマートフォン優先のレスポンシブUI、テーマカラーは `#F97316` 系
